Download

-

Pilih server untuk mengunduh film atau series. Kualitas tergantung server.

Pilih bahasa subtitle untuk diunduh sebagai file .srt

Cara Download

  1. Pilih server dari tab Video
  2. Jika muncul halaman baru, klik tombol download di halaman itu
  3. Pilih kualitas (1080p / 720p / 480p) jika tersedia
  4. Tunggu hingga file terunduh

Tips

  • Gunakan WiFi untuk download file besar
  • Beberapa server mungkin butuh VPN
  • Kalau server mati, coba server lain
  • Subtitle bisa di-load manual di player

Catatan

Fitur download hanya untuk penggunaan pribadi. Hormati hak cipta pembuat film.
