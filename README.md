# 🎬 MovieMatch

MovieMatch adalah website rekomendasi film dan series yang membantu pengguna menemukan tontonan berdasarkan **mood**, **genre**, **kategori**, dan **preferensi pribadi**.

Website ini dibuat dengan HTML, CSS, dan JavaScript, lalu di-deploy menggunakan Vercel dengan dukungan API proxy untuk menjaga API key tetap aman.

---

## ✨ Fitur Utama

- 🔍 **Search Movie & Series**  
  Cari film atau series berdasarkan judul.

- 🎭 **Mood Recommendation**  
  Rekomendasi tontonan berdasarkan suasana hati pengguna.

- 🔥 **Top 10 This Week**  
  Menampilkan film dan series populer minggu ini.

- ⭐ **Favorites**  
  Simpan film atau series favorit.

- 📌 **Watchlist**  
  Tambahkan tontonan ke daftar watchlist.

- ▶️ **Movie Detail & Player**  
  Menampilkan detail film, rating, sinopsis, cast, trailer, dan player.

- 📱 **PWA Support**  
  Bisa di-install seperti aplikasi melalui browser.

- 🛟 **Support Page**  
  Pengguna bisa melaporkan bug, mengirim saran, atau menghubungi admin lewat email dan WhatsApp.

- 🌙 **Dark Mode UI**  
  Tampilan modern bertema gelap dengan aksen merah.

---

## 🧰 Teknologi yang Digunakan

| Teknologi | Fungsi |
|---|---|
| HTML | Struktur halaman website |
| CSS | Styling, layout, responsive design |
| JavaScript | Logic aplikasi dan interaksi user |
| TMDB API | Data film, series, genre, poster, rating, dan trailer |
| Supabase | Data user, favorites, watchlist, dan fitur personal |
| OpenSubtitles | Dukungan subtitle |
| Vercel | Hosting frontend dan serverless API proxy |
| PWA | Manifest, icon, service worker, dan install app |
